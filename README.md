# Rishikesh Munnaluri — Neumorphism Portfolio

A separate recruiter-first portfolio for Rishikesh Munnaluri, designed around a restrained neumorphic visual system.

## Design direction

- Soft raised and inset surfaces instead of glassmorphism
- High-contrast typography so neumorphism never hurts readability
- Emerald accent carried over from Rishikesh's portfolio identity
- Recruiter-first information hierarchy
- Responsive layouts for desktop, tablet and mobile
- Reduced-motion support and visible keyboard focus states
- No heavy animation or unnecessary client-side JavaScript in the first version

## Sections

- Hero and availability
- Profile and recruiter stats
- About
- Education and achievement
- Seven flagship projects
- Experience
- Skills
- Contact

## Tech

- Next.js 16
- React 19
- TypeScript
- Plain CSS design system

## Local development

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Important

This repository is intentionally independent from `Rishikeshsanin/portfolio-main`. The main portfolio is used only as a content/reference source and is not modified by this project.
